Mening uy vazifam
## 5 ta bo'lim bo'yicha 20 ta savol

### Bo'lim 1: Git asoslari
1. git init buyrug'ining vazifasi nima?
2. git status va git diff o'rtasidagi farq nima?
3. .gitignore fayli nima uchun kerak?
4. git commit -m dagi -m nima?

### Bo'lim 2: Branchlar bilan ishlash
5. Yangi branch yaratish va unga o'tish buyrug'i qanday?
6. git merge va git rebase farqi nimada?
7. Merge conflict nima va u qanday hal qilinadi?
8. Branchlarni o'chirish buyruqlari qanday?

### Bo'lim 3: GitHub / GitLab
9. Clone va Fork farqi nimada?
10. git fetch va git pull farqi nimada?
11. Pull Request (PR) o'zi nima?
12. Masofaviy repozitoriyani qanday bog'laymiz?

### Bo'lim 4: Terminal va Oh My Zsh
13. cd, ls va mkdir buyruqlari nima qiladi?
14. Bash va Zsh terminallari farqi nimada?
15. Oh My Zsh plaginlari qanday faollashtiriladi?
16. .zshrc fayli nima?

### Bo'lim 5: Ilg'or Git buyruqlari
17. git stash qachon ishlatiladi?
18. git cherry-pick nima vazifani bajaradi?
19. Oxirgi commitni qanday o'zgartirsa bo'ladi?
20. git log buyrug'ini chiroyli ko'rish parametrlari qanday?
